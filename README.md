# NEO INVADERS // Vector Protocol

洗練されたネオン＆ベクターグラフィックスと重厚なシンセサウンドを備えた、次世代サイバーパンク・インベーダーゲームです。

![NEO INVADERS](https://raw.githubusercontent.com/yamaguchi162217-alt/first/feature/issue-1-stylish-invaders/screenshot.png) <!-- プレースホルダー -->

## 🚀 主な機能・特徴

1. **スタイリッシュなビジュアル & エフェクト**
   - ネオングロー、ベクタースプライト、3層パララックス・スターフィールド（ワープ演出）
   - レーザー光跡、爆発ショックウェーブ、火花・パーティクル演出、画面揺れ（Screen Shake）
   - ピクセル単位で削れるリアルタイム破壊シールド（バンカー）

2. **進化したゲームシステム & コンボ**
   - **コンボシステム**: 敵を連続撃破するとスコア倍率が最大4.0倍まで上昇
   - **EMPオーバードライブ (特殊兵装)**: ゲージが100%になると画面内の敵を一掃するEMPショックウェーブを発動可能
   - **ドロップアイテム**: 3-Way拡散弾、高速レーザー、シールドバリア、即時EMPチャージ
   - **UFO指令船**: ランダムに出現するボーナスUFO（50〜300 PTS）

3. **戦術アドバイザー (CDR. YAMA) 通信システム**
   - HUD上のホログラムアバター（CDR. YAMA）によるリアルタイム作戦指示・状況アナウンス
   - UFO出現アラート、EMP発動通知、コンボ継続コール、戦闘評価デブリーフィング
   - アバタークリックによる戦術通信イースターエッグ

4. **Web Audio APIによるプロシージャル・サウンド**
   - 敵の残数に応じてテンポが加速するダイナミックなベース行進音（4音マーチ）
   - FMシンセ風レーザー射撃音、重低音爆発音、ファンファーレ、コンボチャイム（音量ON/OFF切替可能）

5. **マルチデバイス・レスポンシブ対応**
   - キーボード操作（矢印 / WASD / Space / X）
   - スマートフォン・タブレット向けタッチコントローラー（十字キー / FIRE / EMPボタン）

---

## 🎮 操作方法

| アクション | キーボード | タッチ操作 |
| :--- | :--- | :--- |
| **自機移動** | `◀` `▶` または `A` / `D` | 画面下部 `◀` `▶` ボタン |
| **ショット** | `SPACE` または `J` | 画面下部 `FIRE` ボタン |
| **EMP特殊兵装** | `X` または `K` | 画面下部 `EMP` ボタン |
| **一時停止** | `P` または `ESC` | 右上ポーズアイコン |
| **サウンド切替** | `M` | 右上スピーカーアイコン |

## 🛠️ ローカルでの起動方法

静的Webサーバー（PythonまたはNode.js）で手軽に起動できます。

```bash
# Pythonの場合
python3 -m http.server 8000

# Node.js (npx) の場合
npx serve .
```

ブラウザで `http://localhost:8000` を開いてプレイしてください。
